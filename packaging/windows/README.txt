Kestrel for Windows x64

Run kestrel.exe to open the desktop app.
Run kestrelcli.exe --help for the collection runner and kestrel-mcp.exe --help for the MCP server.

The portable archive can be extracted anywhere. The installer adds Kestrel to the Start menu and installs it for the current user without administrator privileges.

Windows 10 or newer and a graphics driver supporting Direct3D 11 are required.
