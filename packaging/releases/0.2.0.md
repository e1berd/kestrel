Kestrel 0.2.0 adds native RabbitMQ operations and improves GraphQL editing alongside the existing HTTP client.

- RabbitMQ over AMQP 0-9-1 and TLS: publish with broker confirms, fetch messages, subscribe to queues, inspect properties, and acknowledge, requeue or reject deliveries.
- API selector with REST, GraphQL and RabbitMQ icons; a single connection toolbar across API types.
- GraphQL syntax highlighting, full-size Query and Variables tabs, JSON formatting and adding variable names from the query without replacing existing values.
- Invalid GraphQL variables are reported before sending instead of being silently replaced with null.
- TypeScript SDK generation with TanStack Query and rstore adapters.
- OpenAPI, Swagger and Apidog import/export improvements.
- Windows x64 installer and portable ZIP, Linux DEB and AppImage, and macOS Apple Silicon, Intel and universal DMGs. Every package includes the desktop app, CLI and MCP server, with SHA256 checksums.

RabbitMQ files extend OpenCollection and require Kestrel. Existing HTTP collections remain compatible with Bruno. Windows packages are unsigned; macOS packages use ad-hoc signing and are not notarized.

Full changelog: https://github.com/e1berd/kestrel/compare/0.1.0...v0.2.0
